# AgentZ 1.0.52 发布说明

发布日期：2026-11-05。完整变更见 `CHANGELOG.md` 的 1.0.52 条目。

## 新增

- **排队消息可以插队或引导下一轮。** CodeZ 迭代进行中，排队消息除删除外还有两个操作：中断当前迭代并立即发送，或不中断、把文字作为系统引导插入下一轮（`系统提示——用户给出以下引导请关注：…`）。图片仍留在队列里。
- **远程进程经 AgentZ 调用模型。** 远程服务在本机回环上提供 OpenAI 兼容入口，并在未设置时写入 `OPENAI_BASE_URL` / `ANTHROPIC_BASE_URL`。桌面端附上已配置的密钥再请求模型，密钥留在本机。这类转发关闭流式输出。

## 修复

- **多字节字符截断不再让本轮崩溃。** 编码简报、工作流比较和过长的工具输出按字符边界截断，不再切进 `线` 这类字符（`end byte index … is not a char boundary`）。
- **同一目录里检出变化不再把任务卡死。** 新的工具调用跟随当前 HEAD。已经在等批准的那一条不会在新检出上执行，并提示重试同一工具。换到另一个目录仍然拒绝。托管 worktree 只要还属于同一仓库，分支名变化不再使任务失效。
