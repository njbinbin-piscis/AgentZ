# AgentZ 0.9.7 Windows x64 本地候选说明草案

2026-10-08。本说明对应当前源码候选及已有实施证据，不是公开发行公告。package/Cargo/Tauri 与锁文件的 AgentZ 自身版本身份已统一为 0.9.7；工作区包含未提交修改，版本号不能代替源码清单与摘要。主线程本轮 NSIS release 构建会话 17529 仍在运行，本文件没有收到该次最终 installer、退出码、SHA256 或包内容检查结果；任何较早产物不能替代本轮构建结果。

## 用户可见的改进

- **任务环境与变更评审**：既有独立任务环境、完整变更来源、Undo、保留归档及合并预检代码纳入候选。评审窗口切换任务或环境后，旧文件加载和迟到操作结果不再污染新评审；旧合并预检完成后不会继续提交已离开的评审。已发送的后端操作仍由其事务负责，关闭窗口不能撤销它。
- **权限边界**：纳入既有审批绑定、秘密处理和 Windows 受限执行修复；权限与计划、历史显示分离。看到计划条目或读取持久事件不会授予工具执行权。该结论局限于各自证据的自动验证范围，不能推广为所有第三方工具或扩展完整隔离。
- **执行与计划连续性**：本地受支持任务具有 Run/Attempt 持久身份与状态候选。普通 Send、队列续聊及自动续聊不再隐式清除目标；计划通过稳定 identity、revision CAS 及显式目标操作管理。Stop 停止执行，与取消目标分开。重启后的查询与被动恢复不自动重启模型或重放工具副作用。
- **执行事件与历史预览**：本地单 Agent 捕获的聊天事件先提交 SQLite，再发布原事件及已提交通知。历史按 task/run/attempt/environment 与递增序号查询、分页、去重和补读；任务切换隐藏旧任务结果。通知仅提示重新读取数据库，不能直接确认游标或追加文字。预览提供文本与工具状态，不显示原始工具参数、结果或权限请求内容；它不是完整对话恢复。
- **IDE 稳定性候选**：纳入已有 LSP 崩溃恢复和远程 authority/generation 绑定修复。它们有独立自动测试证据，但远程完整工作旅程及实际 Monaco 窗口恢复仍待验收。

相关证据：[评审隔离](AZ-013-parallel-review.md)、[续聊](AZ-020-frontend-continuation.md)、[先提交后发布](AZ-018-chat-stream-integration.md)、[通知补读](AZ-018-committed-notice-integration.md)、[增量重放](AZ-018-incremental-replay-integration.md)、[两阶段读取](AZ-018-two-phase-replay-integration.md)、[版本身份](RC-version-identity.md)。早期证据中尚未实现的说明以后续同范围集成证据为准，不能反向将未跑的验收改为通过。

## 本轮支持范围与已知限制

本轮交付目标为 **Windows x64 unsigned 本地候选**。持久聊天事件及本轮计划/历史查询链路支持其入口已经明确验证的本地 CodeZ 和 WorkZ 单 Agent 任务。Remote、团队、池、后台等入口不能因共用 UI 被视为支持同等恢复语义；远程连接安全修复属于独立候选能力。绕过聊天 collector 的直接 EventSink 事件也未宣称全部捕获。

单个事件 JSON 超过 1 MiB 会明确拒绝存储并使本轮执行失败，发送协作取消信号；不能撤销已完成副作用或保证强制终止不合作的工具。数据库重放页有 4 MiB 累计 payload 预算。前端历史预览上限为 5000 条事件、8 MiB 历史及有限分页，超预算显示错误；文本与工具显示另有预算，长历史浏览尚未完成。

丢失通知可通过手动刷新、回到窗口、联网或任务忙闲变化重新查询；静止前台没有周期补读保证。历史读取失败或损坏明确报错，不修复数据库、不猜测执行成功。旧版没有捕获事件的 Run 可以返回空历史，空历史不代表未执行。

真实 SQLite opt-in 夹具的最新主线程单次结果为：1040 次独立提交 11704.960 ms；1042 条总事件、6 页重开读取 99.696 ms；数据库 40960→552960 字节，Windows x86_64。它证明该夹具路径已实跑，不代表桌面流式延迟、模型吞吐、稳定性 SLA 或多次统计结论。同步每事件提交仍是已知吞吐成本。

## 数据变化与恢复

候选涉及任务环境登记、Run/Attempt、耐久事件及独立计划库。事件与生命周期写入按各自事务提交；计划库与 Run 库不是跨库原子事务。只读查询不创建或迁移缺失库；未知版本、部分 schema 或损坏记录要求显式恢复，不能静默初始化或修补。

测试现有用户数据前应保存项目、任务工作区、会话资料及 `.agentz` 数据目录的受保护备份；活动 SQLite 数据不能仅复制一个主 `.db` 文件后假定完整，需停止写入后备份或使用一致性备份方法。没有完成真实备份恢复、旧版本读取及安装回滚演练，禁止宣称可无损回滚。回退二进制不等于数据回退；未验证的旧版不应直接写入候选数据库。
