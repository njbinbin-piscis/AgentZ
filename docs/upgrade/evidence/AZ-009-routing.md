# AZ-009 按任务恢复前端环境

新隔离任务使用effectiveSessionId（session UUID）创建登记，每轮通过agent_task_get查询，不使用共享worktreeRef。A/B切换与组件重建不作为执行根权威。任务重开同时读取历史与登记；环境错误不隐藏历史，并显示错误。异步任务打开结果有序号防止旧响应覆盖新选择；新任务/新回合/项目切换使旧响应失效。

历史无可验证隔离绑定时不自动创建替代worktree，提供中英文恢复提示。任务选择到既有登记后恢复隔离标识；评审使用冻结base SHA。普通本地/自由任务保持原未绑定兼容路径，正式local环境生命周期由M6继续完善。

验证：`npm run typecheck`通过；`npm test`44项通过，其中新增6项覆盖A/B/A、无缓存恢复、UUID创建、历史绑定缺失、local/free兼容与无效环境拒绝。后端7项测试与宿主check见AZ-008。

未执行：真实原生桌面A/B交叉点击、应用关闭重开及视频/文件核对；按路线图验收要求，本项保持review而非done。服务级测试不冒充UI E2E。

遗留：历史隔离环境无法自动关联旧session；本地历史在隔离偏好开启时可能要求显式新任务，保护优先，不猜目录。journal路由在AZ-012处理；完整未提交评审在AZ-011/013处理。

复盘：UI仅缓存展示，执行时总从稳定task id查询；每次await后检查选择版本，减少异步视图串用。
