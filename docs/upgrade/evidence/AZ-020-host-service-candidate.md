# AZ020 host durable plan service draft

Post-0.9.7 isolated draft, not exported/registered or included in the candidate installer. Added only runtime/durable_plan.rs and this evidence. No Cargo/model/GUI execution; upstream Run review remains outstanding, so no tool activation is authorized by this package.

The service adapts PlanStore behind a small PlanRepository interface, restores turn-local identity/revision from the database and maps kernel pending/in_progress/completed/cancelled without loss. Kernel validation runs after normalization and after merge; persisted current items, never old cache, supply the merge base. Current cancelled/replaced plans cannot be reopened by plan_todo. Ordinary continuation creates no empty plan.

Every write invokes a caller-supplied fresh binding resolver and compares with the turn-captured binding; it compares database head to captured identity/revision before CAS. A late old turn cannot silently adopt a fresh revision. Only a successful repository commit updates the service's projection/token. No EventSink is invoked: the eventual caller publishes kernel cache and emits after success, propagating failures. The service grants no execution permission and does not validate a Run lease itself; trusted host-assigned session/run identity, environment access lease and final resolver validation remain required in the wiring caller.

Minimal export is `pub mod durable_plan` in runtime/mod.rs; parent owns this and Tool registration. Host retains DurablePlanSession per execution, calls recover after trusted binding resolution, and write with a closure performing fresh resolve_binding, a host-generated UUID and first objective. Return Plan carries DTO/revision for emission. Explicit replacement/cancel commands should use the existing PlanStore CAS APIs under stopped-Run/intent checks; they are deliberately not exposed by the plan_todo service.

Four embedded pure fake-repository fixtures cover cancelled mapping/unknown rejection, failed commit and binding mismatch preserving cache, old-turn stale revision and database recovery, cancelled plan not reopened. These fixtures were written but **not run**. rustfmt and diff whitespace check exited0; this confirms formatting, not typechecking or runtime acceptance.
