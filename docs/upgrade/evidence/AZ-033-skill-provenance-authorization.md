# AZ-033 技能来源与能力变更记录

日期：2026-10-06（Asia/Shanghai）  
执行者：Codex

## 交付

- ClawHub 与远程 Marketplace 安装把来源、来源定位、技能 frontmatter 版本、仓库所选版本、安装内容 SHA-256、请求的工具能力及每次安装/升级快照保存在技能配置元数据中。已安装技能页面可查看当前来源、两个版本字段、文件哈希与本机文件匹配状态，以及每次版本变化新增/移除的工具能力。
- 对现有同名技能升级时，安装服务先比较请求工具集合，再写数据库和 `SKILL.md`。若候选新增工具，返回明确列出新增项的错误，旧文件和元数据保持不变；用户可检查能力后卸载旧技能，再主动安装候选版本。减少能力的更新会写入历史记录。
- 卸载先把 `revocation_requested` 事件同步追加到 `skills/.hub/authorization-events.jsonl`，其中保留来源、版本、内容摘要和请求工具；随后删除技能文件、数据库记录和对应 Hub 锁。审计记录表示撤权意图，不谎称删除已成功。
- 技能能力不是长期持久授权：工具仅随用户选入当前任务的技能进入该轮工具集合。卸载会使后续技能发现/选择不再返回它；已运行中的轮次是否立即撤销不在本项承诺范围。
- ClawHub ZIP 安装改为只读取有 1 MiB 上限的 `SKILL.md`，不把不受信任的 ZIP 路径解压到技能目录，避免扩权拒绝前覆盖旧技能以及路径穿越写盘。

## 验证

- `cargo test --manifest-path src-tauri/Cargo.toml --lib skills:: --locked`：5/5 通过，覆盖旧配置向后兼容、SHA-256、工具集合差异、安装→兼容升级→新增工具升级拒绝→撤权记录→卸载及 Hub 锁清理。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib install_ --locked`：3/3 通过，额外覆盖只读取 ZIP 内 SKILL.md（不写入同目录恶意路径）及超过 1 MiB 失败关闭。
- `npm run typecheck`、受影响 TS 文件 ESLint、受影响 Rust 文件 `rustfmt --check` 均通过。

## 边界与复盘

- SHA-256 校验的是本机已安装文件与安装时快照是否一致；上游当前没有被本项验证的签名/可信摘要对照，故不能据此宣称包来源已被密码学认证。
- 新增工具能力当前采取失败关闭并要求显式卸载后重装；本项没有新增逐项授权对话框。
- 验证使用本地 SQLite 和临时文件夹替代注册表实网；没有进行实时 ClawHub/Marketplace 网络验收或原生 GUI 操作。本项接受标准的安装、升级、撤权与卸载路径由服务集成测试覆盖；桌面显示仍需后续真实候选版检查。
