# AZ-027 · ADR-003：权限、授权与危险动作契约

2026-10-05，Asia/Shanghai。状态：产品/宿主实施契约；负责与审核：Codex自检。定义即将实现的行为，不宣称当前全部生效。前置身份契约见 AZ-002；实际执行与持久化分别由 AZ-028、M2 和后续资源工具任务完成。

## 当前代码证据

`src/components/chat/PermissionCard.tsx` 展示工具名、描述与输入，提供 Allow once/Deny。`src-tauri/src/commands/interactive.rs` 按 request_id 从进程内 map 移除一次性 sender，发送 bool；缺失请求明确返回 not found/expired，但 sender 投递失败当前被忽略。`AppState.permission_responses` 是内存 map，不能作为重启后的有效授权证明。`chat_turn.rs` 的调用配置 bypass_permissions=false，并发出 waiting_permission 生命周期事件。源码中存在审批接线，不等于六类资源均已有可靠边界。

worktree 是独立代码目录；进程、网络、其他应用与账号能力仍需专门的资源控制。权限设置、技术可用性、用户批准和实际完成是四个独立状态，不能用一个“已允许”标签代替。

## 默认授权层级

| 层级 | 默认对象与动作 | 授权方式与期限 | 不包含的能力 |
| --- | --- | --- | --- |
| P0 查看 | 当前任务授权根中的普通源码读取、已选产物预览 | 发起任务所授的读范围，持续至该任务停止/范围撤销；重启重验身份 | 外部目录、凭据、账号数据、应用屏幕与网络发送 |
| P1 工作区编辑 | 当前任务/环境的普通源码新建、编辑与可恢复改动 | 用户委派或明确项目编辑设置形成 grant；当前任务环境有效；重复同范围操作不反复询问 | `.git`、身份/审批/秘密数据库写入，进程启动，永久清除，发布 |
| P2 扩展资源 | 已声明的进程模板、网络目的地、浏览器 profile、桌面 surface 或连接器只读账号 | 按具体资源升级；默认当前 attempt，有界模板可复用；attempt结束/环境变化失效 | 通配账号、全桌面、未知子进程、副作用扩大、发送/发布 |
| P3 危险副作用 | 发送消息、发布/部署、共享内容、支付、永久删除、外部账号状态变更 | 完成具体预览后，人批准精确对象与参数；一次消费，批准后最多10分钟且不超过当前attempt | 笼统“持续工作”授权、自动重试外部发送、未经预览的新内容或目标 |

只有能力 provider 在该平台已实现且通过能力检查，才能进入授权流程；Unavailable/Unsupported 直接解释能力缺口，不能展示“批准后就能执行”。“宽范围执行”是显式选择的资源 grant，不豁免P3、秘密出口或失效范围校验，不宣传为已验证OS沙箱。

## 六类资源矩阵

| 类别 | 授权对象/边界 | 可执行动作与升级 | 有效期 | 撤销与失效 |
| --- | --- | --- | --- | --- |
| 文件 | Project/Task/Environment ID + canonical root +解析后的目标；外部附件绑定单文件/目录，不能推导父目录权限 | P0读取、P1普通编辑；外部路径单独选取升级；永久删除P3。内部元数据仅宿主服务能力可写，不能作为模型普通文件权限 | P0/P1当前任务环境；外部选取默认当前attempt；P3一次/≤10分钟 | 撤销根或附件立即阻止后续访问；改绑、根丢失、symlink/reparse重定向须重验/重授权 |
| 进程 | executable身份、argv、cwd、环境变量允许项及子进程/文件/网络能力说明 | 未授权不启动；P2受控模板可以复用；参数扩大或任意shell升级。直接运行Git/脚本可能运行hook、filter、driver，不能仅按命令名算作只读 | 当前attempt；明确模板可复用到本次任务，绑定environment和模板版本 | 撤销停止接纳新进程；已启动进程进入可取消状态，不能谎称所有子进程已停止；终止证明由owned-job生命周期实现 |
| 网络 | scheme/host/port或固定provider、账号、HTTP语义、可发送的数据范围与成本上限 | P2公开读取/已配置模型调用按已授范围；redirect、新origin、私密内容外发或写接口重新升级；外部发布P3 | 当前attempt；模型provider可按显式项目配置持久允许，但每次任务重验预算与账号 | 撤销后不发新请求；不能撤回已发送数据；账号/endpoint变更或超预算失效 |
| 浏览器 | provider + profile/account + tab/origin；上传另绑源文件；下载另绑目标路径 | P2限定tab读取/低风险输入；页面正文不是授权；登录、上传、账号写操作按资源升级，提交/发送/购买P3 | 当前attempt；导航跨origin或账号切换重新匹配；P3一次/≤10分钟 | 关闭tab、退出profile、账号变化失效；撤销停止输入；已提交副作用先对账，不盲重试 |
| 桌面 | OS会话、具体应用实例/window或surface、可截图区域与输入动作；不自动覆盖其他显示器/应用 | P2选定surface截图和可逆输入；新应用/弹窗/敏感登录区域扩大需升级；应用中的删除/发送/支付仍P3 | 当前attempt；窗口身份变化立即重验；锁屏、断连、会话切换失效 | 撤销后不再截图/输入；停止不能撤销已发出的键鼠；provider不可用时标记Unsupported |
| 连接器 | connector安装实例 + account稳定ID + API操作与资源ID + credential reference | OAuth登录不等于所有业务动作获准；P2被选账号读取；写入逐项升级，邮件/Slack发送、发布、权限分享P3 | 当前attempt；只读资源可显式项目持久；P3一次/≤10分钟 | 断开/换账号/权限scope变化立即失效；凭据不传模型；请求结果未知先查询远端对账 |

资源之间不隐式互授：文件允许不等于shell允许；shell允许不等于外部消息批准；浏览器允许不等于已登录账号可外发；已有OAuth凭据不等于发送权限。OS级隔离尚未实现时必须明确进程可能拥有其OS用户的权限，不能把工具前置检查称为完整沙箱。

## 宿主审批意图与状态

PermissionIntent(schema1)至少包含 intent/request ID、project/task/environment ID与绑定版本、run/attempt ID、actor、provider/account/surface定位、action、规范化参数/产物摘要、资源描述、风险层级、有效期、可逆性与恢复依据。canonical参数与资源、账号、内容/附件hash一起形成摘要；秘密只用reference及必要存在状态，不能进入描述、日志、摘要原文或审批卡。

宿主产生与校验意图；模型、工具输出、网页、文件与其他Agent只能提出请求，不能创建grant或充当批准者。人批准的卡片必须显示所属任务/环境、实际目标、动作和后果；切换视图不将旧卡片改绑新任务，也不能凭active session替换原身份。

actor身份由宿主可信UI通道确定，不能相信调用输入自报human。审批界面、权限设置和凭据解锁属于受保护surface，Agent不能借桌面、浏览器或插件点击自批/改变授权；独立Webview与扩展IPC不能取得批准者权限。该隔离必须真实实现与测试后才标为支持，不以“已显示按钮”作为证据。

状态：draft → pending → approved/denied/expired/revoked；approved → claimed → executed/failed/unknown。claim须持久、原子、一次消费，再发生副作用。失败与未知结果不回到approved；重新尝试产生新意图，外部副作用先对账。清楚区分审批成功、投递成功、执行开始和执行完成；sender已关闭不返回“成功批准”。

排队、执行前、重启恢复时重新验证scope/hash/expiry/revocation/能力版本。参数、内容、账号、surface或环境改变，旧批准不适用。重启保留待审记录，但旧run/attempt授权默认失效，P3不会自动续用；持久项目grant需显式签发并逐次重验，不把内存bool提升为持久信任。

P0/P1的基本任务scope允许同一任务正常续聊，归档、显式撤销或环境绑定改变时失效；停止某次attempt不扩大权限，也不妨碍人查看已有产物。P2默认attempt期限、P3单动作期限与基本任务scope分别持久化，不能混成一个全局“总是允许”开关。

撤销立即阻止尚未claim的动作；对已claim/运行中的动作发取消请求并显示真实终止/未知状态，不伪称副作用已撤回。关键本地事务可以保留worker/租约完成恢复处理（如AZ-016），取消等待与中止事务分别显示。授权更新/撤销通过宿主审计追加事件，模型工具不能删除这些事件。

## 具体动作评审

| 示例 | 决定与理由 |
| --- | --- |
| 用户委派修复任务，Agent反复编辑登记worktree中的src/a.ts | 当前P1范围复用；同任务普通可逆改动不反复弹窗 |
| 已授worktree编辑，脚本试图写主项目或访问其他目录 | 单独升级；worktree不是OS权限边界，进程必须受控或显式声明宽执行范围 |
| 执行一次已批准测试模板，下一次argv加入上传或额外环境变量 | 参数/能力摘要改变，模板grant不适用；重新审查 |
| Agent想把密钥写入审批描述或模型提示 | 拒绝秘密出口，使用secret reference；不靠用户点击放行原密钥 |
| 公开URL读取redirect到不同origin或内网地址 | 不继承原origin grant；网络解析/redirect边界由宿主验证 |
| 浏览器读取标签页后提交已登录邮箱的发送表单 | 读取grant不足；先形成收件人/正文/附件的P3具体预览 |
| 桌面已选编辑器窗口，弹出另一个应用登录框 | 旧surface授权不自动扩大；暂停该输入并重新匹配 |
| 用户批准Slack消息A，模型随后修改文字或频道 | 内容/目标hash改变，旧批准不能执行消息B |
| 用户说“持续工作”，Agent完成任务后自行发布版本 | 未有具体发布授权，拒绝；完成工作只产生可审查产物 |
| 用户在Task B界面看到Task A的待审批卡 | 卡片仍归A，必须显示A/其环境；不能改绑B；失效/撤销就不可批准 |
| 程序重启时发现之前邮件请求claimed但没有结果 | 标记unknown并远端对账，不自动重发；不能重用一次性批准 |
| 用户取消合并等待，但事务正处理Git恢复 | UI表示仍在完成事务/恢复；租约保持至真实处理结束，不提前放行冲突操作 |

以上为契约例评，不是已运行的权限/原生/模型测试。六类资源均已有对象、期限、撤销与升级定义，自检通过；执行验证须在后续实现的故障注入与真实旅程中完成。

## 迁移、回退与后续任务

AZ-028将intent/决策/claim/审计独立持久化，旧requestId+bool入口仅适配新意图，不猜测或扩张范围；未知schema或缺身份/摘要时拒绝。兼容旧调用不允许降级回无范围批准；保留拒绝原因与历史，不删除旧数据库。

秘密失败关闭/OS保护/脱敏由AZ-029/030/031/077/078完成；browser/desktop实际能力按M9与支持矩阵验收。进程、网络和账号的执行器必须把上述资源声明落实为实际边界；未实现时展示准确的支持状态。M3 Gate不因本契约完成而通过。

回退时保留审计与意图库；无法验证新grant的旧版本不得当作allow。撤销和失效记录不被覆盖。首期取舍采用受控默认+同scope复用，减少重复批准，同时让不可逆副作用仍有具体、一次性的授权证据。
