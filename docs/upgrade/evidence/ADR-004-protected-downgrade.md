# ADR-004：秘密格式变更后的回退契约

2026-10-06，用户在推荐“受保护备份恢复门禁”方案后答复“好的，继续”，据此采用推荐路径。

AZ-029 按加密失败关闭、原子保存及固定依赖接入的代码范围验收。跨秘密格式版本直接降级不受支持：旧版未解密视觉 API key 的事实保留，不宣称兼容通过。

发行前 AZ-063 必须提供受保护、版本化的配置和密钥备份以及恢复验证；AZ-065 更新/回退必须检查秘密格式版本，无法恢复兼容快照时拒绝跨格式降级。恢复需要同时恢复相匹配的配置与密钥，并验证凭据可用性。旧明文配置字节复制不能当作受保护备份。

本决定允许推进 AZ-030 系统主密钥保护；不放行 M8 或任何发行、回滚、桌面验收。AZ-009/AZ-013/AZ-032 的 GUI review 保留。
