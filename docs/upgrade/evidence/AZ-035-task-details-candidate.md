# AZ-035 pure task-detail aggregation candidate

New task_details.rs exposes Source<T>, Sources, ArtifactReferences, TaskDetails and aggregate(scope: PlanBinding, sources: Sources). It is a pure function over host/store-validated observations: no file/database reads or initialization, renderer path resolution, permission grants, model/tool execution or mutations. Parent owns exports and future read-only host integration.

Source status distinguishes available (value + explicit independently observed version), missing, unsupported, unavailable, stale and unknown. All supplied available environment/Run/Plan/event/artifact identities must match the captured task/environment scope; PlanBinding must exactly match. Current event Cursor additionally requires the available Run and its current Attempt, and nonnegative sequence. Budget is root-task observational Snapshot and retains unknown fields/currencies; no cost/time/concurrency enforcement is inferred. Artifacts are host-verified opaque IDs, bounded and unique, not arbitrary paths. Unavailable statuses carry no raw error/secret text.

Cancelled plans retain complete persisted objective/items/status/revision; runtime empty projections are not used. atomic_snapshot is always false and source versions remain independent; this is not an atomic cross-database snapshot or a fresh binding resolver. Host must label failures/stale references explicitly and validate storage before supplying Available, rather than fabricate zero/empty values. Missing, unknown and unavailable are not interchangeable.

Five inline pure contract fixtures cover status serialization/non-atomicity, full cancelled plans, cross-task/environment rejection, current-event/Run/Attempt association and bad source versions/artifact references. They are actual source fixtures but have NOT been executed here; parent runs unique Cargo validation after lib export. Only rustfmt was executed successfully. No GUI/native IPC/model/platform or AZ-035 formal acceptance is claimed. No shared source, configuration or ledger was modified.
