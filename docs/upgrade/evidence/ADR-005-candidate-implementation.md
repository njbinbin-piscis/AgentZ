# ADR-005 候选实现与正式验收分离

2026-10-06。用户已要求跳过本轮GUI步骤并持续推进其他工程工作。

原台账同时用里程碑Gate限制开工和验收，M1 GUI待验收导致后续已满足代码依赖的任务也不能实施。本轮增加preparing状态：只允许所有任务级依赖done的任务进入候选实现；负责人、开始时间、证据及历史照常记录。

doing/review/done仍需原全部依赖和Gate满足。preparing不能直接done，不算完成，也不能让它的下游依赖任务开始实现。任何里程碑通过仍要求其全部任务done，原生GUI/真实模型/平台运行条件保持未验收。

台账隔离验证已覆盖候选状态拒绝未完成代码依赖、允许等待Gate的候选实现、禁止绕过Gate转入review，并验证失败不会写入正式台账。此调整只改变可追踪的候选工作排期，不放行部署、发布或产品验收。
