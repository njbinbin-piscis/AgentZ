# ADR-008：统一 GUI / Tauri 验收豁免

状态：已接受（用户决定，2026-10-11）

## 背景

剩余升级任务的多数验收条目要求真实 GUI 或 Tauri Webview 验证（例如 AZ-032 的真实 Webview 正反测试、AZ-036 的原生面板核对）。本机无法完成这些原生验收。用户在 ADR-007 中已为 AZ-009 / AZ-013 接受过单项豁免，本次决定对剩余 GUI 验收统一豁免。

## 决定

1. 对所有验收条目中仅依赖真实 GUI / Tauri Webview / 原生面板人工核对的部分，视为“GUI 验收豁免”。
2. 豁免不改变其余验收：类型检查、单元/集成测试、Rust 测试、代码复审、契约与数据库测试仍必须通过，并写入证据。
3. 豁免任务在 ledger 的 `review_notes` 中必须写明“GUI 未验证（ADR-008 统一豁免）”，reviewer 记为“用户豁免（ADR-008）”或独立复审人，不得写成已原生验证。
4. 豁免不适用于外部账号 / 外部平台依赖（例如 macOS、Linux 凭据、签名公证账号）。这些仍按 `blocked` 处理（见 ADR-007）。
5. 实际工时若为估计值，必须标注 `unmeasured`。

## 风险

- 原生 GUI 行为（窗口焦点、Webview 隔离、Monaco 与原生输入）未经人工核对，可能存在回归。
- 安装器与签名相关验收（AZ-064）不属于本豁免。

## 复核要求

后续若获得 GUI 验收窗口，应补测并在 `docs/upgrade/evidence/` 中追加记录。
