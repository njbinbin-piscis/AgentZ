# ADR-003：按代码现状收束执行视野

2026-10-05。对照 `crates/agentz-task-state`、宿主命令和 WorkZ 界面之后，修订计划版本为 3。已完成任务的验收记录保持原样。

## 决定

1. AZ-028 收回到原始验收：审批绑定动作、参数摘要、任务、环境与有效期；参数变化、过期、换任务和重启使旧授权失效。该项转入 review。原生点击仍是未验证项，不构成继续把相邻工具表面写进同一任务的理由。
2. 从 AZ-028 拆出三件尚未完成、且各自可以单独验收的工作：AZ-080 递归预检之后的路径替换，AZ-081 固定内核排除目录遍历，AZ-082 LSP 结构化返回中的路径过滤。操作系统隔离仍由既有 AZ-034 承担。`restrict_unapproved_background` 只裁剪工具注册表，不计入 AZ-034 已完成。
3. 当前周期只处理已经可审阅的缺口，不新开 doing。顺序是：AZ-009 与 AZ-013 的原生核对，然后 AZ-029 的固定依赖复核，以及收窄后的 AZ-028。AZ-079 是 M1 里唯一尚未开始的代码修复；review 降到上限以内再进入 doing。
4. M2 及以后仍留在台账中。M2 的开工条件不变：M1 Gate 通过。入口已经明确，见各任务下一步，避免再使用“确认入口代码与基线”作为当前视野的动作。

## 不改变的事实

M0 保持 passed。AZ-004 保持 blocked。没有任何 done 记录被改写为未完成或提前完成。M5–M9 不延期为 deferred，它们只是还没到可执行视野。稳定版仍然等待 MB 与 M2–M7。
