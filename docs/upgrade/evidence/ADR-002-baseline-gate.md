# ADR-002：将真实模型效果基线与确定性工程修复解耦

2026-10-04；理由：开始实施时AZ-003已确认确定性Git和环境缺口，原M0将真实模型样本和人员预测作为所有修复的前置，形成不必要等待。

计划版本升级为2：M0聚焦产品契约、身份契约、风险复现、支持策略与当前执行容量；AZ-004迁至新增MB“真实任务效果基线”，MB前置M0。AZ-006以AZ-003已确认工程基线替代未完成的AZ-004作为前置，保留未知资源与人力记录。

M1/M3/M7仍等待M0；实际使用效果相关任务仍依赖AZ-004；M8增加MB Gate前置，所以不能绕过真实模型、成本或性能证据发布稳定版。没有把AZ-004标记完成，也没有把合成测试当真实模型基准。

当前仅已知Codex负责本轮工程执行；无额外人员承诺。无需未知长期团队容量就能启动本轮高风险修复。模型/预算问题已异步向用户询问，未收到答案视为未确认。
