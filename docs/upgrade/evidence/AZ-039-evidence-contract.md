# AZ039 evidence-display contract review

2026-10-10. Read-only source inspection. No model, tests, PR, merge, GUI or build executed. This supplies conservative presentation rules for a read-only delivery summary candidate.

CurrentTaskRun fields are run_id/task_id/environment_id/attempt_id, execution, delivery and updated_ms. Execution is queued/running/cancelling/succeeded/failed/cancelled/interrupted. Discovery verifies task identity, enums, nonnegative safe timestamp and execution/delivery consistency. These are current authoritative Run facts when obtained via scoped host query, not a renderer tool-text inference. A succeeded Run means host finish found no classified failed/cancelled/timeout terminal condition; it does not certify tests, content correctness, accepted deliverables or external publication. Interrupted also covers timeout/uncertain completion; do not render it as successful cancellation. The task summary is a separately read non-atomic snapshot.

Delivery is not_ready/awaiting_review/accepted/rejected. RunStore transition to succeeded sets awaiting_review; all nonsucceeded executions require not_ready. decide_delivery persists accepted/rejected only via a succeeded/current-attempt/awaiting-review CAS and same-transaction lifecycle event. This durable domain field exists, but current host search found no production caller of decide_delivery. Therefore UI may display an actual scoped Run delivery value if returned, including existing accepted/rejected metadata, but must not imply the product currently exposes a complete acceptance action or bind that decision to a particular artifact version. There is no applied/published Run delivery enum. Chat event “published_durably” means local event publication after storage, not external artifact publishing.

Artifact kind Validation is only a label supplied to explicit capture together with title and relative file path. Host safely captures bytes and derives ID/version/digest; neither ArtifactStore nor capture command parses a validation result or verifies a test process, expected exit status, input revision or independent oracle. An arbitrary report saying “passed” can be stored as validation. Display “validation artifact recorded” or “validation status unknown/not verified”; never a Passed badge from kind/title/content/tool text or a successful capture. Artifact hash proves payload identity, not correctness. Likewise ChangeSet kind is a label, not a complete reviewed Git change or an applied receipt.

Existing scoped merge preview/receipt and retained recovery ref are a separate operation contract; a real receipt may support “merge transaction reported merged” for that operation, not accepted/published for all task artifacts. Archive receipt is retention/cleanup evidence. ExternalActionStore is a domain intent/start/unknown/result ledger, not an automatically connected delivery publisher or provider acknowledgment. The old openPr response is not a durable task/version-bound published source. Do not infer external publication from branch name, PR-shaped URL, trace message or generated text. Show applied/published Unknown/Not recorded until a concrete scoped version-bound persisted source is integrated.

Safe candidate output: exact current execution and delivery (source unavailable/missing explicit), recorded ChangeSet scope/version identifiers, count of recorded artifact versions and their historical binding/digests, validation evidence presence with status unverified, and explicit lack of acceptance/apply/publication provenance. No action controls, auto replay, merge, PR, permission grant or synthesized pass decision are justified by these inputs. Cross-source revision differences and independently read snapshots must remain visible limitations.
