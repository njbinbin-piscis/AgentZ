# AgentZ 1.0.43 发布说明

发布日期：2026-11-02。完整变更见 `CHANGELOG.md` 的 1.0.43 节。

## 新增

- **在内置浏览器打开 HTML。** HTML 文件工具栏新增"在内置浏览器打开"按钮，以 `file://` 在内置浏览器标签页加载该文件，脚本、存储、网络均可用。该按钮使用当前聊天会话的浏览器页，会替换其当前显示的页面。

## 修复

- **子代理回退到主模型。** 子代理自己的模型（agent 设置或全局 flash 模型）无法运行时，例如 API Key 失效，会在主代理正在使用的模型上重试一次。仅在子代理尚未调用工具、未修改文件时才会重试。

## 说明

- 引擎引用仍为 piscis-engine `v0.8.72`。
