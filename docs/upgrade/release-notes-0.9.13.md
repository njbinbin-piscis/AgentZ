# AgentZ 0.9.13 发布说明

发布日期：2026-10-18。版本号与 `CHANGELOG.md` 的 0.9.13 条目一致。

本版本只清理聊天窗口。0.9.12 把计划、执行历史、任务概况、交付观察、任务文件和产物查看器直接插进了 CodeZ 与 WorkZ 的对话区，并带有手动刷新按钮。这些内容和右上角抽屉、折叠任务列表、顶栏用量环重复。

**本版本未通过上线验收门禁。** 未验收项与用户测试用例仍见 `docs/upgrade/acceptance-0.9.12.md`。

## 界面调整

- 对话区只保留折叠任务列表、消息流和输入框。WorkZ 底部仍保留隔离、团队、智能体选择和任务评审入口。
- 打开会话时在后台读取已保存的计划，写入折叠任务列表。没有「刷新计划」按钮。
- 变更与产物仍从右上角抽屉查看。用量仍在顶栏圆环里。
- 去掉 WorkZ 底部「高级选项」折叠，团队、智能体和隔离起点选择回到原来的底栏。

## 已知限制

- 未通过验收门禁（台账中 M2 至 M8 与 MB 未全部通过，AZ-069 未完成）。发布时未把 `release-readiness` 接入 `release.yml`，否则安装包任务不会开始。
- 安装包未签名。macOS 安装包未公证，首次打开需要手动允许。
- macOS 与 Linux 安装包未在真机上运行。
- 0.9.12 的已知限制仍然适用，见 `docs/upgrade/release-notes-0.9.12.md`。
