## 本轮目标与边界

目标是可追踪源码、实际可构建的 Windows x64 本地候选及其验证记录。用户希望后续提交发布，本轮先准备候选；本文件和子代理没有创建提交、PR、推 tag、dispatch CI、公开 Release 或部署。主线程统一控制源码快照、版本、宿主验证和打包。

平台冻结 Windows x64，渠道为 candidate，本轮采用 **unsigned本地安装包候选**；未签名不称稳定正式发行。package/Cargo/Tauri版本已统一为0.9.7，主线程记录当前大量dirty修改形成的源码候选身份与产物摘要，不把未提交修改冒称既有提交SHA对应内容。不得以候选名、文件存在或单元测试通过宣称稳定版、Beta全部通过或正式支持跨平台。

本轮只整合既有修复、完成适配它们的 Windows 编译/资源/打包阻断修复、运行针对回归、保存版本/摘要/已知问题；不新开 M2–M9 的依赖未完成功能，不扩大桌面自动化/连接器/团队/自动发布能力。
