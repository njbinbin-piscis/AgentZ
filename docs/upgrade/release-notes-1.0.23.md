# AgentZ 1.0.23 发布说明

发布日期：2026-10-26。完整条目见 `CHANGELOG.md` 的 1.0.23 章节。

## 变化

- **修复千问等网关因“连续重复工具调用”返回 400。** 发送请求前，把历史中连续多轮完全相同的“工具调用 + 结果”折叠成最后一轮，并在结果末尾注明重复次数；已因此卡死的会话下次发送即可恢复。
- **防循环更早、更有力。**
  - 同一工具以相同参数连续调用 3 次时提醒模型换做法（轮询类工具除外）。
  - `code_run` 反复得到等价结果（忽略耗时等数字和内部操作编号）时，第 4 次起提醒，第 8 次起直接拦截，并要求向用户汇报阻塞原因。
  - 同一调用的提醒被忽略 3 次后，升级为拦截。
  - 防循环历史会从已保存的会话历史重建，新一轮对话不再从零开始计数。

## 已知限制

- 拦截只针对 `code_run` 的“相同命令、等价输出”；其他工具仍使用原有较高阈值。
- 小模型仍可能忽略提醒，拦截后的结果会明确要求其向用户汇报。
