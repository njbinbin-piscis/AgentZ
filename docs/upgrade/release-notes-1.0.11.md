# AgentZ 1.0.11 发布说明

发布日期：2026-10-22。版本号与 `CHANGELOG.md` 的 1.0.11 条目一致。

AgentZ 1.0.11 修复编辑器 Ctrl+S 保存误关标签的问题，给工具输出加了均衡的截断机制，并新增 Cursor 式的 `wait` 工具等待长程后台任务。

## 修复

- **Ctrl+S 保存误关文件标签**：文件保存走「临时文件 + 原子重命名」，Windows 文件监视器会把重命名覆盖误报为删除，前端随即关掉标签（未编辑时）或弹出「文件已被删除」（编辑时）。监视器后端对 Remove 事件先做存在性校验——文件还在则重分类为修改；前端对 deleted 事件再延迟复核（读文件确认不存在才处理），双层消除误报，真删除的行为保持不变。
- **模板对话框单选按钮错位**：打开文件夹弹出的项目模板对话框中，radio 原先单独一行居中，现改为与模板名同一行左对齐，描述缩进对齐文字。

## 改进

- **工具输出均衡机制**（`shell` / `code_run` / `process_control`）：此前按字节头尾截断，单个超长行（压缩 JS、base64、进度条）会吃满整个预算、白耗 token 且无有效信息。现在三步均衡：① 逐行上限 1000 字符，超长行中间省略并保留行首行尾；② 按整行头尾选取（55% 头 + 45% 尾），不再切碎行；③ 截断时完整输出落盘到 `.agentz/logs/tool-output/` 并在结果中给出路径，agent 可用 file_read/file_search 查看省略部分而不必重跑命令。展示预算同步收紧（shell 24KB/12KB、code_run 16KB/8KB、process_control 24KB/12KB；code_run 捕获上限由 8KB 提升到 64KB 以便落盘完整）。
- **新增 `wait` 工具**：主动等待长程后台任务——按 `bg_id` 等单个任务，或不带参数等待本会话全部后台任务（`scope=any` 首个完成即返回 / `all` 全部完成），`until=ready` 等就绪条件；无任务可等时可做有上限的纯延时（`seconds`）。全部等待在宿主侧单次调用内完成，不占用 LLM 迭代。原 `process_wait` 保留，两者文案已互相同步引导。
