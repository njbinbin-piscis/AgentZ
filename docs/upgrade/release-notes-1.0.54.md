# AgentZ 1.0.54 发布说明

发布日期：2026-11-05。完整变更见 `CHANGELOG.md` 的 1.0.54 条目。

## 新增

- **CodeZ 的目录只显示在 CodeZ 里。** 路径、最近项目、关闭和本机/远程标记从主标题栏移到 CodeZ 顶部。WorkZ 和 BotZ 各自管理自己的目录。
- **可以再开一个 AgentZ。** 标题栏按钮会启动另一个进程，并且不会重新打开当前窗口已经占用的项目。
- **BotZ 办公室可以移出成员并更换目录。** 机器人卡片和工位都能把该成员移出。加入两个办公室后，「加入办公室」仍然在。工具栏可以另选工作目录，任务板改跟新目录。
