# AgentZ 1.0.28 发布说明

发布日期：2026-10-28。完整变更见 `CHANGELOG.md` 的 1.0.28 节。

## 修复

- **回合运行中后台任务完成，不再另起一个看不见的回合。** 通知直接送进正在运行的回合，agent 在下一步前处理；会话空闲时才启动单独的续跑回合。未被消费的通知会改走续跑，不会丢失。
- **后台 server 运行时 agent 卡死。** 进程结束后读取输出最多等 5 秒，即使子进程仍持有管道也不再挂住。
- **shell 命令在自身 120 秒超时时被 agent 循环同时截断**，来不及转入后台。循环超时现在取工具自身超时 + 30 秒。
- 被终止的后台任务不再触发自动续跑；已报告就绪的任务只在失败退出时再报告；重启恢复的通知不再阻挡实时事件。
- 浏览器工具单次操作上限 90 秒，并响应停止。
- 应用退出时结束所有后台任务；已结束任务记录最多保留 64 条。

## 新增

- 后台 `shell` / `code_run` 新增 `service: true`：用于 dev server、watcher 等常驻进程，无运行时长上限，就绪时通知一次，仅异常退出时再通知。
