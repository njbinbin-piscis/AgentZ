# AgentZ 1.0.40 发布说明

发布日期：2026-11-02。完整变更见 `CHANGELOG.md` 的 1.0.40 节。

## 新增

- **设置项"计划未完成时自动续跑"。** 位于设置 → Agent，默认开启。关闭后模型停下即结束本轮，即使计划里还有未完成的待办。
- **"从此处分叉"改为菜单。** 点击弹出两项：仅复制上下文（模型当前还能看到的最近消息），复制完整历史（分叉点之前的全部消息）。菜单跟随主题渲染。

## 修复

- **agent 说要等用户确认却继续执行。** 回复在提问或等待确认时，不再触发未完成待办的续跑提醒。提醒上限（2 次）改为按轮计，工具调用不再清零。提醒文本也要求模型在需要用户决定时直接提问并结束本轮。
- **分叉的新会话丢失历史。** 原来只读最近 1000 条、只复制文字。现在复制全部消息及工具调用、工具结果、turn 序号和附件。分叉整个对话时，滚动摘要和状态帧也一并复制。

## 说明

- 引擎引用为 piscis-engine `v0.8.71`。安装包仍编译 vendor 中的同一份内核。
