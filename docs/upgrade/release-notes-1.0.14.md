# AgentZ 1.0.14 发布说明

发布日期：2026-10-24。版本号与 `CHANGELOG.md` 的 1.0.14 条目一致。

AgentZ 1.0.14 在没有 Git 仓库的文件夹里可以直接初始化仓库，并避免执行记录数据库被锁住时整轮 Agent 停掉。

## 新增

- **初始化新仓库**：源代码管理面板在「此文件夹中未找到 Git 仓库」下提供按钮，在当前文件夹执行 `git init`。若该文件夹已经位于上层仓库内，则拒绝再套一层，并显示那个仓库的路径。

## 修复

- **Agent 轮次因 `run store: database is locked` 中止**：执行记录、预算和预留共用 `.agentz/runs.db`。回滚日志模式下，一个连接在读时另一个连接的写入会被挡住，等待 5 秒后整轮失败。现在该库使用 WAL，读写可以同时进行，等待时间延长到 15 秒。已有的 `runs.db` 会在下次打开时自动切换。

## 待真机冒烟

- 打开一个没有 `.git` 的文件夹，在源代码管理面板点「初始化新仓库」，确认随后能看到分支和更改。
- 跑一轮会连续写执行记录、同时结算预算的 Agent 任务，确认不再出现 `database is locked`。
