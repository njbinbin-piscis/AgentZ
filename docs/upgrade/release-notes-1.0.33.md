# AgentZ 1.0.33 发布说明

发布日期：2026-10-28。完整条目见 `CHANGELOG.md` 的 1.0.33 节。

## 修复

- **模型"最大输出 Token"与上下文窗口相同（如 256000/256000）时，每步迭代要几分钟，Agent 还报告"工具输出为空"。** 输入预算被算成 0，导致每一步都执行完整压缩（多一次总结 LLM 调用），并把历史压到 3–4 条消息，刚返回的工具结果被丢掉。现在输出预留最多占上下文窗口的 1/4，预算为 0 时不再触发压缩。

## 变更

- **每个模型单独设置上下文窗口。** 模型条目新增"上下文窗口"（0 = 继承主模型），运行时按所选模型取值；此前所有模型共用一个全局值。
- **设置面板重新组织。** 新增"Agent"页，包含策略模式、最大迭代次数、Shell/写文件确认、始终允许的工具、子代理委派和 MCP 服务器；"模型"页只保留模型相关设置。"最大输出 Token"增加说明，并在超过上下文窗口 1/4 时给出警告。设置面板默认打开"通用"页。
