# AgentZ 0.9.16 发布说明

发布日期：2026-10-18。版本号与 `CHANGELOG.md` 的 0.9.16 条目一致。

本版本修四处界面问题：Mermaid 空框、会话分叉重名、运行中停止按钮外圈不转、远程开发等弹窗固定深色。

**本版本未通过上线验收门禁。** 未验收项与用户测试用例仍见 `docs/upgrade/acceptance-0.9.12.md`。

## 修复

- **Mermaid：** 清洗 SVG 时保留 `<style>`、`<foreignObject>` 与内部文字标签；用 HTML 解析避免严格 XML 遇到 `<br>` 或 CSS `>` 时返回空字符串。聊天与预览共用该逻辑，并按当前深浅主题初始化 Mermaid。
- **会话分叉命名：** 新分叉标题为 `(N) 原标题 (fork)` 或 `(N) 原标题 (fork @ checkpoint)`。会去掉已有的前置序号和分叉后缀再取下一个 `N`，避免嵌套和重名。
- **停止按钮外圈：** 在系统关闭动画（`prefers-reduced-motion`）时，运行指示器仍保持循环旋转；亮边改用主题强调色，浅色主题下也看得见。
- **弹窗主题：** 远程开发连接框、项目模板框、任务评审与技能修订面板改用 `--bg-elev`、`--border`、`--text`、`--accent` 等全局主题变量。

## 已知限制

- 未通过验收门禁。发布时未把 `release-readiness` 接入 `release.yml`，否则安装包任务不会开始。
- 安装包未签名。macOS 安装包未公证，首次打开需要手动允许。
- macOS 与 Linux 安装包未在真机上运行。
- 0.9.15 的已知限制仍然适用，见 `docs/upgrade/release-notes-0.9.15.md`。
