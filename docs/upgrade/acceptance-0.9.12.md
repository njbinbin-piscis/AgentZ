# AgentZ 0.9.12 未验收清单与用户测试用例

日期：2026-10-18。适用版本：0.9.12（发布后在发布安装包上测试）。

本文件有两部分：

1. 未验收清单：台账 `docs/upgrade/plan.json` 中 46 个未完成项（`status` 不为 `done`），以及它们的当前判断。
2. 用户测试用例：每个未验收项一条用例，外加 0.9.12 本版本的 7 条回归用例。

**本版本未通过上线验收门禁。** 发布说明见 `docs/upgrade/release-notes-0.9.12.md`。

## 一、结果记录方式

每条用例的 `结果` 填写：`通过`、`失败`、`阻塞`（缺少环境或账号）、`未实现`（功能不存在，入口或行为与预期不符）。

- 失败：附上现象、截图路径、版本号（设置中可见）和复现步骤。
- 阻塞：写明缺少什么（系统、账号、证书、人数）。
- 结果回报后，由维护者按台账规则回写 `plan.json`：`done` 需要复核人、证据、完成说明、复核备注、完成时间、实际工期和 GUI 状态。不能用一次口头通过代替台账记录。

执行者列说明：`用户` 表示可在本机发布版本上直接测试；`维护者` 表示需要开发者环境或内部数据；`外部` 表示需要 macOS/Linux 账号、证书、真实 SSH 主机或真实 Beta 用户。
