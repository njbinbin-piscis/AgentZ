# AgentZ 0.9.8 发布说明

发布日期：2026-10-17。版本号与 `CHANGELOG.md` 的 0.9.8 条目一致。

0.9.7 已于 2026-10-06 发布，本版本不覆盖该发布；0.9.8 是新的版本。

## 新增

- CodeZ 与 WorkZ 共享项目会话：同一项目在两个界面中看到同一批会话。团队会话在 CodeZ 中只读。
- 模式切换快捷键：Ctrl/Cmd+Shift+N 切换到 CodeZ，Ctrl/Cmd+Alt+N 切换到 WorkZ。
- 连接器 OAuth2 授权：连接器行上有“授权”和“刷新授权”按钮。授权使用 PKCE，回调校验 `state`，token 存入该连接器的凭证文件。

## 变更

- 失败的 agent 轮次在诊断日志中记录 `task_id` 与 `environment_id`，导出的诊断可以定位到失败任务。
- 首次使用清单在设置面板关闭后重新读取配置状态。
- 备份校验对不支持的 schema 版本给出明确拒绝原因。

## 已知限制

- 上述共享、快捷键、OAuth 三项的原生桌面旅程没有人工跑过，仅有自动化测试覆盖。
- OAuth 只针对本地假 token 端点测试，未对接真实提供商。
- Windows 安装包未签名。macOS 与 Linux 安装包未在真实机器上验证。
