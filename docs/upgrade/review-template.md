## 周期计划与复盘

- 周期：；日期范围（Asia/Shanghai）：；容量：；负责人：

- 临时新增/移除范围：任务编号、原因、谁决定、对预测的影响。
- 完成：done任务及证据；review/doing/blocked：实际状态与下一步。
- 承诺完成率：已验收承诺项 / 开始时承诺项（新增项另列）。

- 指标：任务成功率、人工干预、成本、宿主故障、性能变化；样本与缺失项。
- 估算校准：预计/实际差异；剩余范围；新预测区间；变动原因。
