# AgentZ 1.0.35 发布说明

发布日期：2026-10-31。完整变更见 `CHANGELOG.md` 的 1.0.35 节。

## 修复

- **后台任务结束后自动续跑总是用主模型。** 续跑现在使用该会话用户最后一次设置的模型、Agent 和技能，而不是全局默认。
- **模型选择不按会话隔离。** 每个会话单独记住自己的模型、Agent 和技能选择，切换会话时自动恢复；新会话沿用当前选择。只改选择不发送也会同步给后端，续跑同样生效。

## 说明

- 升级前已有的会话还没有单独保存的选择，切过去时保持当前选择，在里面发一次消息或改一次选择后开始单独记住。
- Workz 面板暂未改动。
