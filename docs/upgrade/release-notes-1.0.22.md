# AgentZ 1.0.22 发布说明

发布日期：2026-10-26。完整条目见 `CHANGELOG.md` 的 1.0.22 章节。

## 变化

- **后台任务可在终端标签中查看。** 每个后台任务行新增“在终端显示”按钮，点击后在底部面板打开只读的“后台输出”标签：先显示已捕获的输出，再持续跟随新输出直到任务结束，支持颜色，并显示状态行和截断提示。

## 修复

- **中文状态栏文案。** 1.0.21 的“本会话 / 本项目 / 输入 / 输出”标签在中文界面中显示为问号，已修复。

## 已知限制

- 后台输出标签是只读视图，不能输入命令；标准输出与标准错误分别读取，二者之间的先后顺序不保证。
