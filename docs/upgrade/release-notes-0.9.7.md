## 本轮候选改进

- 远程文件、工具及上下文读取绑定原始主机与连接世代，旧连接请求失败关闭，避免重连后写到替换主机。远程监听恢复、LSP 退出、端口转发状态与重试预算加入生命周期控制。
- Run/Attempt 持久状态、排队取消与执行结果候选实现，成功执行和用户交付验收分别记录。
- 本地语言服务断连后清理诊断、重建连接并同步打开文档，限制恢复次数并显示恢复状态。
- 扩展 Webview 使用 opaque iframe、受限 CSP 和精确消息来源校验；修复 CSP 注入位置及属性伪装问题。资源按面板令牌与注册目录读取。
- 增加手动、未签名、仅工作流产物的 Windows x64 候选构建准备，以及离线输入/产物清单。资源摘要前置检查失败时不继续构建，候选清单不会把签名标为已验证。

以上描述源码候选行为，不表示路线图验收全部通过；具体变更范围需在最终版本构建前与源码指纹复核。
