# AgentZ 1.0.16 发布说明

发布日期：2026-10-25。版本号与 `CHANGELOG.md` 的 1.0.16 条目一致。

## 新增

- **会话导出与导入**：对话面板标题栏的 ⇪ 导出当前会话，默认保存到项目内 `.agentz-sessions/<标题>.agentz-session.json`，可随项目提交。另一台电脑 pull 后点 ⇩ 导入，生成新会话继续工作。导出内容包含全部消息、工具调用与结果；原项目根目录下的绝对路径在导入时改写为本机项目根目录。工作目录、WorkZ 团队与资源池等本机设置不导出。
- **文件修改卡片**：Agent 的 `file_edit`、`file_write` 在对话中显示为卡片，包含文件名、`+N −M` 行数和可展开的彩色 diff，点文件名在编辑器中打开。

## 变更

- 编辑器标签栏的横向滚动条只在鼠标位于标签区时显示。

## 修复

- **工具参数含代码时 Agent 迭代中止**：JSON 字符串中的原始换行、制表符、控制字符和单个反斜杠会先修复再解析；仍无法解析时告知模型重试（两次后提示拆分大文件写入），不再以空参数执行工具。
- 工具输出中的 ANSI 转义和控制字符在交给模型前清理，进度条重绘只保留最终状态。
- 中文 Windows 上 GBK 与 UTF-8 混合的输出按行解码。
- `code_run` 与 shell 默认设置 `PYTHONUTF8=1`、`PYTHONIOENCODING=utf-8`（调用方已设置时不覆盖）；工具说明补充了 cmd.exe 引号写法和 Windows PowerShell 5.1 向原生程序传引号的规则。
