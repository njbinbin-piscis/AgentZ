# AgentZ 1.0.13 发布说明

发布日期：2026-10-24。版本号与 `CHANGELOG.md` 的 1.0.13 条目一致。

AgentZ 1.0.13 让编辑器标签按完整文件名占宽。标签多到一行放不下时，标签条横向滚动，不再把每个标签压成文件名开头几个字母。

## 修复

- **编辑器标签过窄**：标签原先平均收缩，最小 72px、最大 200px，文件名被截成几个字母加省略号。现在标签宽度跟着文件名走，悬停仍显示完整路径。放不下时可用鼠标滚轮左右滑动，标签条底部有一条细滚动条。

## 待真机冒烟

- 打开多个文件名较长的标签，确认能看全文件名，滚轮和底部滚动条都能把后面的标签滚进来。当前标签在切换后仍滚入可见区域。
