# AgentZ 1.0.18 发布说明

发布日期:2026-10-26。完整变更见 `CHANGELOG.md` 的 1.0.18 条目。

## 变更

- **文件修改卡片 diff 更易读。** 新增行为绿底绿字、删除行为红底红字，左侧带彩色竖条，`+`/`-` 标记加粗；深色与浅色主题均已调整。
- **后台任务输出被重定向时给出提示。** 若后台任务因命令把输出写入文件(`> out.log`、`2>> err.txt`、`| Tee-Object x` 等)而没有捕获到输出，「查看输出」会列出目标文件并可直接在编辑器打开。`shell` 与 `code_run` 工具说明建议后台任务不必重定向输出(输出会自动捕获)，但仍允许重定向。

## 已知限制

- diff 新配色与重定向提示未在已安装的构建上做人工界面验证。
