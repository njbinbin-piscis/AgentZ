# AgentZ 1.0.9 发布说明

发布日期：2026-10-21。版本号与 `CHANGELOG.md` 的 1.0.9 条目一致。

AgentZ 1.0.9 将 `shell` / `code_run` 的沙箱强度绑定到已有的安全级别设置，解决开发者在沙箱内无法联网拉取依赖的问题，并重组了设置面板的标签页归属。

## 变更

- **安全级别决定沙箱强度**：严格 = 零网络 AppContainer 隔离；均衡（默认）= 以当前用户身份在 Job Object 中运行，可访问网络、本机服务（localhost）、系统代理与 cargo / npm 等用户工具链缓存，工作目录仍锁定在项目内，超时与取消终止保留；开发者 = 禁用沙箱，命令以当前用户运行，工作目录可离开项目。沙箱模式只能由设置决定，工具入参无法修改。实测 AppContainer 即使授予网络能力也无法访问回环服务（需管理员 LoopbackExempt 豁免），故均衡档采用当前用户联网运行以保证本地开发服务器工作流可用。
- **设置面板新增「通用」标签页**：界面语言、安全级别、默认工作目录与项目列表、应用变更记录、配置状态/目录、诊断日志导出迁至「通用」；「模型」标签页仅保留提供商、模型与 MCP 配置。
