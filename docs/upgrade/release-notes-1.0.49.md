# AgentZ 1.0.49 发布说明

发布日期：2026-11-03。完整变更见 `CHANGELOG.md` 的 1.0.49 条目。

## 新增

- **远程项目用内置浏览器看服务。** 连上远程后，已经在听的端口和后来新出现的端口都会转到本机。内置浏览器打开 `localhost` 或 `127.0.0.1` 时走这条转发，本机端口号不同也会打开实际转发到的端口。
- **在 Linux 远程上调试。** Python 使用远程虚拟环境。Delve 和 js-debug 在远程本机监听，IDE 经端口转发连接。js-debug 会上传到远程，用远程的 Node 运行。

## 修复

- **远程项目里打开文件。** `/home/...` 这类绝对路径留在远程机器上，不再接到工作区后面。工作区被拼重时会先折回再读。文件不存在时，错误里会写明是哪台机器在应答。
- **计划的 Build 卡片会在继续对话时关掉。** 再发一条消息，或点取消，卡片关闭且不执行计划。点 Build 仍会按计划执行。
- **工具说明和工具实际接受的参数一致。** `file_list` 和 `file_search` 写明路径必须是目录。`code_run` 不再把 `python -m` 后面的文件路径说成缺少模块；在 Windows 上会把 PowerShell 语法指到 shell 工具。命令示例不再默认写成只有 Windows 才成立的写法。技能不再要求代理去读工作区外的文件。

## 变更

- **远程目标。** Linux 远程可以连接，没有 Node 时上传一份 Linux 运行时。macOS 远程需要已经装有 Node 18 或更新版本。原生 Windows 远程会被拒绝，并提示改用 WSL 或 Linux。原生模块与远程系统不一致的扩展留在本机，不会复制过去。

## 内核

- 内核仍基于 piscis-engine `v0.8.72`，本版修改了随仓库提供的工具说明和诊断。
