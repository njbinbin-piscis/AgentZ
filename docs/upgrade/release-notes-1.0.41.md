# AgentZ 1.0.41 发布说明

发布日期：2026-11-02。完整变更见 `CHANGELOG.md` 的 1.0.41 节。

## 新增

- **OpenCode Go 服务商。** 设置 → 模型里选择 OpenCode Go，只需填写 API Key，端点已内置。请求会带上当前会话的 `x-opencode-session` 和 AgentZ 的 User-Agent，这是 OpenCode 的要求，缺少时会返回 400 `MissingSessionID`。之前按"自定义 OpenAI 兼容"配置的 OpenCode 模型需要改选此服务商。
- **清空通知。** 通知下拉在"刷新"旁新增"清空"按钮。

## 修复

- **同一项目只允许一个窗口打开。** 另一个 AgentZ 窗口已打开该项目时，再打开会被拒绝并提示，不再出现两个窗口共用同一项目状态。
- **第二个实例不再打断后台任务。** 第二个窗口不会把第一个窗口仍在运行的后台任务标为已中断，也不会接管它们的续跑；每个运行中的任务持有系统级租约。
- **工作区状态不再被其他窗口覆盖。** `workspace.json` 原子写入；没有打开项目的窗口不会清除上次打开的项目，只有用户主动关闭项目才清除。
- **多窗口同时保存设置。** 写 `config.json` 加跨进程锁；表单加载后另一个窗口改过设置时，保存会被拒绝并重新加载最新值。窗口重新获得焦点时设置也会刷新。
- **多实例下 SQLite 报"数据库忙"。** 内核数据库和 `index.db` 遇到锁最多等待 5 秒，不再立即失败。
- **通知重复。** 同一次运行重试多次会产生多条通知。现在每个任务只显示一行，角标按任务计数，打开一行会把该任务的通知全部标为已读。
- **通知相关文字已国际化。** 下拉标题、铃铛提示、刷新、清空、加载中、空状态均有中英文。

## 说明

- 引擎引用为 piscis-engine `v0.8.72`。安装包仍编译 vendor 中的同一份内核。
