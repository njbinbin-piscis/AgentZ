# AgentZ 0.9.15 发布说明

发布日期：2026-10-18。版本号与 `CHANGELOG.md` 的 0.9.15 条目一致。

本版本统一了 CodeZ 与 WorkZ 的项目与会话视图：同一项目的会话在两端均可直接打开并续写，两端共用同一份最近项目清单。

**本版本未通过上线验收门禁。** 未验收项与用户测试用例仍见 `docs/upgrade/acceptance-0.9.12.md`。

## 新增与调整

- **会话双端同步续写：** 在 WorkZ 中点击 CodeZ 来源的项目会话不再强制跳转到 CodeZ，而是直接在 WorkZ 中打开并继续对话。CodeZ 与 WorkZ 作为同一项目会话库的两个同步视图工作，仅 WorkZ 的无项目（自由）会话独立于项目之外。
- **全局最近项目清单（选择文件夹 + 历史项目）：** CodeZ 保持 IDE 单项目工作方式，顶栏文件夹按钮（及路径栏）新增下拉菜单，分为「选择文件夹…」和「最近打开的项目」（与 WorkZ 共用 `workz.json` 项目注册表，支持一键切换或从列表移除）；CodeZ 未打开项目时的欢迎页也直接列出最近项目。

## 已知限制

- 未通过验收门禁。发布时未把 `release-readiness` 接入 `release.yml`，否则安装包任务不会开始。
- 安装包未签名。macOS 安装包未公证，首次打开需要手动允许。
- macOS 与 Linux 安装包未在真机上运行。
- 0.9.14 的已知限制仍然适用，见 `docs/upgrade/release-notes-0.9.14.md`。
