# AgentZ 1.0.30 发布说明

发布日期：2026-10-28。完整变更见 `CHANGELOG.md` 的 1.0.30 节。

## 修复

- **stdio MCP 服务器启动慢或不响应时，发送后一直“思考中”，停止无效。** 回合启动无限等待 `initialize` / `tools/list`。现请求有超时（启动 60 秒、工具调用 300 秒），按请求 id 匹配回复；启动失败的服务器 5 分钟内跳过而不是每回合重启；并发回合共用一次连接。
- **MCP 工具目录过大撑爆模型上下文。** 每个服务器的工具定义限制约 120 KB（描述截断到 1024 字符，单个超过 16 KB 的 schema 跳过），被丢弃的工具记录到日志。
