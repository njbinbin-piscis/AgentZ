# AgentZ 1.0.17 发布说明

发布日期:2026-10-26。完整变更见 `CHANGELOG.md` 的 1.0.17 条目。

## 新增

- **子代理委派。** 主 Agent 可通过 `delegate`、`call_fish`、`task` 工具把工作交给子代理。设置中新增「子代理委派」(关闭 / 仅研究 / 自动,最大并发 1–16);已注册的 Agent 可选择是否允许被委派。聊天中显示子代理卡片和实时活动;可写任务在隔离 worktree 中运行并在合并前审阅。
- **BotZ 工作区(预览)。** 新的例行 Bot 工作区,含房间视图、头像和审阅面板。设计见 `docs/botz-design-2026-10-25.md`。
- **办公室自有成员。** 创建办公室时直接多选 Bot,团队模板只作为可选的一键预填;已有办公室可在工具栏「👥 成员」中增删成员,Bot 卡片上可直接「加入办公室」。移出仍有进行中任务的成员时会保留到任务结束。旧办公室首次打开时自动把模板成员和协作约定转为自有,原任务池保留。
- **运行位置与远程边界。** 标题栏显示当前项目的运行位置(💻 本地 / 🔌 SSH、容器、WSL),悬停可查看能力表。远程项目可用编辑器、终端、LSP、调试、扩展和单 Agent 对话;WorkZ 团队池和 BotZ 办公室暂只支持本地,切到这两个模式时显示说明横幅,并提供「打开本地项目」和「回到 CodeZ」;后端也会直接拒绝远程目录。
- **资源管理器「显示隐藏文件」开关。** 开启后列出点文件、`.agentz` 和被 gitignore 的条目;`.git`、`node_modules`、`target` 等仍然隐藏。选择会被记住。
- **面向视觉模型的浏览器工具(RobotZ 0.1.14)。** 导航、点击、输入、滚动等操作后自动附带压缩的视口截图(仅视觉模型),连续相同的画面会跳过。`screenshot` 支持按元素(`ref`/`selector`)或区域(`x,y,width,height`)截图,长边最多 1568px(整页 2000px,高度上限 6000 CSS px),默认保存到 `.agentz/screenshots/`。

## 变更

- `.agentz` 始终显示在资源管理器中(只隐藏其内部数据库),即使 `.gitignore` 列出了它。
- 视觉模型识别改为与 provider 无关的匹配表;可用环境变量 `AGENTZ_VISION_MODELS` 追加规则。
- Windows UI 自动化 `type_text` 在目标无法接收键盘输入时明确报错,不再静默什么都不输入。
- 内核文件工具统一通过与区域设置无关的路径文本助手输出路径,中文路径在非中文 Windows 区域下保持完整,`\\?\` 前缀不再泄漏到工具输出。
- OpenAI 兼容流式接口会丢弃空名称的工具调用、补全缺失的调用 id,并按确定顺序组装。

## 已知限制

- 需要真实模型的子代理委派验收步骤见 `docs/subagent-delegation-acceptance-2026-10-25.md`,尚未在发布构建上完成。
- 浏览器自动截图和「显示隐藏文件」按钮未在已安装的构建上做人工界面验证。
- 办公室成员管理和远程边界提示未在已安装的构建上做人工界面验证。
