# AgentZ 1.0.27 发布说明

发布日期:2026-10-27。完整英文变更见 `CHANGELOG.md` 的 1.0.27 条目。

## 修复

- **后台任务完成后的自动续跑回合运行期间,用户发消息会报 `task queued/running or goal mutation active`。** 该回合对界面不可见,会话看起来是空闲的。现在后端会发出 `host_turn_started` 事件:会话显示为运行中,新消息自动排队,停止按钮可以取消它。仍撞上占用的发送会自动重试,不再直接失败;续跑回合与用户回合抢占时会重新等待,不再被丢弃。
- **内置浏览器面板会卡死且不响应输入。** 页面操作挂起会一直占着浏览器锁,后续调用全部排队;现在每一步都有超时,导航也不再无限等待 `load`。点击改为真实鼠标事件,键盘输入/粘贴/按键会转发到页面,并新增前进/后退按钮。
- **模型选择不同步。** 状态栏与输入框现在互相跟随模型选择,提供商被删除的模型会被清除。
- **模型价格设置里的币种下拉被裁切且没有主题样式。**
- 占用报错现在会带上持有者信息(`task_key`、阶段、持续时间),便于排查。

## 未改动

- 点击停止后的实际停止耗时(最长可能接近一分钟)尚未定位,不在本版本范围内。
