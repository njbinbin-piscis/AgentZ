# AgentZ 1.0.15 发布说明

发布日期：2026-10-25。版本号与 `CHANGELOG.md` 的 1.0.15 条目一致。

AgentZ 1.0.15 按 VS Code / Cursor 的远程开发模型补齐远程工作区：读代码的功能和 Agent 开发工具都在代码所在的机器上执行，或把结果写回那里。

## 变更

- **远程项目可以用 Wiki、仓库记忆、代码地图、符号查找和调用图**：以前这些命令要求本机目录，遇到 `agentz-remote://` 直接失败。现在索引在本机源码镜像上计算（镜像只作缓存），生成的 `.agentz/REPO_WIKI.md`、`WIKI_DEEP.md`、`AGENT_CODING_BRIEF.md`、`REPO_MEMORY.md` 写回远端仓库。代码地图的提交热力在远端执行 `git log`。
- **远程会话里的 Agent 工具 `lsp`、`read_lints`、`code_run`、`file_diff`**：以前在远程会话中被移除。现在语言服务在远端启动；`read_lints` 在没有语言服务时于远端运行 `cargo check` 或 `tsc --noEmit`；`code_run` 在远端执行；`file_diff` 读取远端文件。

## 修复

- 远程工作区可以「初始化新仓库」。
- 标题栏对话按钮的提示改为「显示/隐藏对话面板」，不再提到图谱。
- **Windows 下 shell 输出只剩最后一行**：折叠重复行的逻辑丢掉了所有与下一行不同的行，PowerShell 和 cmd 的多行输出看起来像被截断。现在每一行都保留，只折叠连续重复行。
- **长输出保留结尾**：200 KB 采集上限改为保留开头和结尾各一半，中间标注未采集字节数，报错所在的最后几行不再丢失；截断处不再留下半个字符。
- **cmd 能输出中文**：`echo`、`cd`、`dir` 等内建命令不理会 `chcp 65001`，中文变成 `?`。命令改在切换代码页后启动的子 cmd 中执行，命令里的引号和 `&` 原样传递（以前引号被转成 `\"`）。非 UTF-8 的行按系统代码页解码。
- **grep 能搜到 UTF-16 和 GBK 文件**：以前非 UTF-8 文件被静默跳过，现在与读文件使用同一套编码识别，并去掉匹配行开头的 BOM。
- **含中文的 Git 路径**在源代码管理、Agent 任务审阅、审批和代码地图中显示为文件名，不再是八进制转义。
- **网页抓取正确解码 GBK/GB2312 页面**（按响应头或 `<meta charset>`）。

## 已知限制

- 严格模式（AppContainer）下，cmd 的 `dir` / `for`、PowerShell 的当前位置和子进程启动会因无法列出工作区上级目录而失败，cmd 内建命令的非 ANSI 字符仍显示为 `?`。这是不向沙箱泄露上级目录内容的取舍；shell 工具说明已提示改用 PowerShell、`file_list` / `file_search`。
