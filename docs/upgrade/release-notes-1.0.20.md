# AgentZ 1.0.20 发布说明

发布日期:2026-10-26。完整变更见 `CHANGELOG.md` 的 1.0.20 条目。

## 变更

- **文件修改 diff 作为过程信息处理。** 只有当前运行中最新一轮显示编辑卡片和回合 diff;发送下一个任务后消失,恢复历史会话时也不显示。更早轮次的编辑工具调用不再显示为卡片或批次行,发送时释放已保存的回合 diff。「回滚本轮」仅对最新一轮可用。
- **diff 最多占 5 行高。** 展开的编辑卡片与回合 diff 改为 5 行高的滚动区域,不再增长到 220–320px。
- **编辑卡片配色可读。** 新增行绿底绿字、删除行红底红字,左侧带彩色竖条,`+`/`-` 加粗;深色与浅色主题均适用(1.0.18 只调整了回合 diff 卡片)。

## 已知限制

- 以上界面改动未在已安装的构建上做人工验证。
- 发给模型的历史工具调用入参(含新旧文本)未做压缩,本版本只改界面显示。
