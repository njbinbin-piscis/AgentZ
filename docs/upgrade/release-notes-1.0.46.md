# AgentZ 1.0.46 发布说明

发布日期：2026-11-03。完整变更见 `CHANGELOG.md` 的 1.0.46 条目。

## 修复

- **点击链接不再白屏。** 之前点击 Agent 输出里的链接，整个 webview 会跳到目标页面，界面白屏。现在统一拦截：网络地址用内置浏览器打开，项目文件用预览打开，预览不支持的类型（Office、压缩包、安装包、音视频、文件夹等）用系统默认程序打开。BotZ 没有内置浏览器，网络地址用系统浏览器，文件用系统默认程序打开。CodeZ 里打开二进制文件也会交给系统程序。

## 内核

- 内核仍为 piscis-engine `v0.8.72`。
