# AgentZ 1.0.34 发布说明

发布日期：2026-10-29。完整条目见 `CHANGELOG.md` 的 1.0.34 节。

## 修复

- **子代理（`delegate` / `task`）运行 150 秒就被杀掉。** 主循环的通用工具超时远早于子代理自身的超时（只读 240 秒、可写 900 秒）触发，已收集的部分结论全部丢失。现在自行管理超时的工具只受 1 小时的绝对上限约束。
- **子代理把步数全用在工具调用上时返回"无结论"。** 现在宿主会带上子代理的任务说明和已收集的工具结果（按模型预算裁剪），再请求一次结论报告。
- **中止后再发新消息，上一轮的工具调用气泡消失。** 实时工具步骤只显示在最后一条消息上，新一轮开始时被清空；有排队消息时也不会重新加载上一轮。现在步骤会固定到所属气泡，并且总是重新加载历史。

## 新增

- **设置 → Agent 页新增子代理迭代次数与超时。** 迭代次数默认取主代理设置的一半（至少 10）；超时默认 900 秒（最大 3600）。智能体清单中的配置仍然优先。
