# AgentZ 1.0.45 发布说明

发布日期：2026-11-02。完整变更见 `CHANGELOG.md` 的 1.0.45 节。

## 新增

- **对话表单留在会话流里。** `chat_ui` 表单显示在 Agent 提问的位置，随消息一起滚动。回答或超时后变灰只读，显示提交的内容（或"未回答"）。恢复历史会话时同样显示灰色表单，且不会再触发任何操作。

## 修复

- **超时的表单会真正消失。** `chat_ui` / `chat_ui_listen` 最长等待 5 分钟，却被引擎 150 秒的工具上限提前截断，表单因此残留。现在这两个工具自己管理超时，调用失败时表单立即收起。
- **切换会话后表单不丢。** 切走再切回仍在运行的会话时，Agent 还在等的表单会恢复，不必干等超时。
- **切换窗口不再重复弹"设置已保存"。** 窗口重新获得焦点只静默刷新设置；只有真正保存才提示。

## 说明

- 引擎引用仍为 piscis-engine `v0.8.72`。
