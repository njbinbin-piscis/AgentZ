# AgentZ 1.0.38 发布说明

发布日期：2026-11-01。完整变更见 `CHANGELOG.md` 的 1.0.38 节。

## 修复

- **弹出层和后面的面板融在一起。** 菜单、会话列表、任务和待办卡片、对话框共用一个稍亮的背景。
- **`file_list` 在 `dirs_only` 时把只有文件的目录报成空目录。** 目录能读开但没有子目录时，结果为「无子目录（文件数未知）」。读目录失败则报错。
- **关闭 AgentZ 时远程服务被直接断开。** 已连接的远程 agentz-server 会先收到关闭请求，停掉它自己拉起的进程，再断开 SSH。

## 变更

- **CodeZ 和 WorkZ 都能查看并停止后台任务。** CodeZ 会话上方的列表已去掉。CodeZ 从状态栏向上打开，WorkZ 从任务栏向上打开，用的是同一份项目列表。每一行标出来源（CodeZ、WorkZ、WorkZ 团队或协作成员）。打开所属会话时留在对应模式。
- **远程 `shell` 和 `code_run` 支持 `background=true`。** 命令在远端启动，并登记到同一份任务列表，可以看输出、等就绪、停止。

## 说明

- 应用崩溃或被强杀时，远端后台进程可能还在，重新打开后不会自动接回。
- 远程项目如果查不到本地会话库，来源显示「未知来源」。
