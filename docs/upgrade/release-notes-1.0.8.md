# AgentZ 1.0.8 发布说明

发布日期：2026-10-21。版本号与 `CHANGELOG.md` 的 1.0.8 条目一致。

AgentZ 1.0.8 修复了在坚果云等云盘同步目录中执行 `code_run`（例如 `node -v && echo OK`）时桌面进程闪退的问题，并提高了浅色主题下终端输入命令的对比度。

## 修复

- **坚果云工作区沙箱闪退**：开发工具链命令在申请 AppContainer ACL 租约之前改走只读句柄锚定的 Job Object；目录扫描改为有上限的迭代遍历；目录项按未对齐记录读取；`code_run` 与 `shell` 在 8 MB 栈的工作线程上执行。
- **浅色终端输入看不清**：xterm 补齐深浅色 ANSI 调色板。浅色模式下 `brightYellow` 为 `#713f12`，`yellow` 为 `#854d0e`，并启用 4.5 的最小对比度。
