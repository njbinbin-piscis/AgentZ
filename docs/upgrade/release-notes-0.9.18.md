# AgentZ 0.9.18 发布说明

发布日期：2026-10-19。版本号与 `CHANGELOG.md` 的 0.9.18 条目一致。

本版本让 WorkZ 对话气泡随窗口变宽，Mermaid 图可以跟着气泡放大。

**本版本未通过上线验收门禁。** 未验收项与用户测试用例仍见 `docs/upgrade/acceptance-0.9.12.md`。

## 变更

- **Agent 回复：** 宽度为对话栏的 80%，左右各留 10%。去掉原先 `720px` / `820px` 上限，最大化后气泡变宽。
- **用户消息：** 仍靠右，最宽 90%，左侧至少留 10%。短消息保持内容宽度。
- **Mermaid：** SVG 铺满气泡宽度，窗口变宽时图变大，窄窗口时仍限制在气泡内。

## 已知限制

- 未通过验收门禁。发布时未把 `release-readiness` 接入 `release.yml`，否则安装包任务不会开始。
- 安装包未签名。macOS 安装包未公证，首次打开需要手动允许。
- macOS 与 Linux 安装包未在真机上运行。
- 0.9.17 的已知限制仍然适用，见 `docs/upgrade/release-notes-0.9.17.md`。
