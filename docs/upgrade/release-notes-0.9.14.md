# AgentZ 0.9.14 发布说明

发布日期：2026-10-18。版本号与 `CHANGELOG.md` 的 0.9.14 条目一致。

本版本只修一个问题：Windows 上 WorkZ 会话列表里同一个项目出现两次，一个是 `C:\Projects\AgentZ`，另一个带 `\\?\` 前缀。

**本版本未通过上线验收门禁。** 未验收项与用户测试用例仍见 `docs/upgrade/acceptance-0.9.12.md`。

## 修复

- 0.9.11 及更早版本把带 `\\?\` 前缀的项目路径存进了 `workz.json`。0.9.12 只改了返回给界面的路径，没有处理已保存的路径，所以两种写法被当成两个项目。现在加载时去掉前缀并合并重复项，保留较新的打开时间。合并结果在下次添加或移除项目时写回文件。
- 添加、移除项目时也先去掉前缀，界面传来带前缀的路径同样能匹配。
- WorkZ 保存的范围、最近工作目录、各项目最后打开的任务，读取时同样去掉前缀。

## 已知限制

- 未通过验收门禁。发布时未把 `release-readiness` 接入 `release.yml`，否则安装包任务不会开始。
- 安装包未签名。macOS 安装包未公证，首次打开需要手动允许。
- macOS 与 Linux 安装包未在真机上运行。
- 0.9.13 的已知限制仍然适用，见 `docs/upgrade/release-notes-0.9.13.md`。
