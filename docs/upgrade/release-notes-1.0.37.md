# AgentZ 1.0.37 发布说明

发布日期：2026-11-01。完整变更见 `CHANGELOG.md` 的 1.0.37 节。

## 修复

- **多会话共用一个浏览器页面。** 每个会话有自己的标签页。CodeZ 面板和该会话的 `browser` 工具都只操作这一页，其他会话不能把它跳走或点掉。关闭浏览器标签只关闭当前会话的页面。
- **WorkZ 右侧可以打开内置浏览器。** 任务栏有「浏览器」按钮。该任务的 Agent 调用 `browser` 时用这个任务自己的页面，和 CodeZ 以及其他任务分开。
- **任务通知看不出是哪个对话。** 通知现在显示会话标题和最后一条助手回复。

## 变更

- **BotZ「加入房间」改用应用内下拉框**，和其他菜单一致。

## 说明

- 所有会话仍共用一个 Chromium 进程，浏览器操作会排队，登录状态（Cookie）也是共用的。
- 团队里的 Koi 成员仍然没有 `browser` 工具。
