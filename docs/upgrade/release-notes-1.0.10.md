# AgentZ 1.0.10 发布说明

发布日期：2026-10-22。版本号与 `CHANGELOG.md` 的 1.0.10 条目一致。

AgentZ 1.0.10 引入后台长任务：构建、测试、开发服务器等耗时命令可由 agent 显式放入后台，或在前台超时后自动转入后台继续运行；任务完成（或就绪）后，宿主会自动在原会话中续跑一轮，让 agent 接着核对结果、失败修复。同时修复了 CodeZ 多会话并行时的串话问题。

## 新增

- **后台长任务原语**：`shell` / `code_run` 新增 `background` 参数（及 `notify_on`、`ready_port`、`ready_log` 就绪条件）。任务由内核 `BackgroundProcessRegistry` 托管（Windows 下仍走原有沙箱强度与 Job 进程树），输出进入环形缓冲并落盘到 `.agentz/logs/bg/<bg_id>.log`（单流 8MB 上限）。新增 `process_wait`（宿主侧阻塞等待，支持等退出/等就绪）、`process_output`（游标增量读输出）、`process_kill`（整树终止）工具；`process_control` 的后台启动改为受管注册。
- **完成自动续跑**：任务完成/就绪后宿主在原会话派发一轮合成续跑（携带命令、退出码、耗时与输出尾部），会话忙时停放（30 分钟过期）、同一任务只派发一次、每会话自动续跑上限 6 次（用户发送后重置）。任务状态经 `background_task` 事件推送到收件箱与界面。
- **界面**：CodeZ 面板新增「后台任务」区（查看输出尾、终止、跨会话跳转），会话行与 WorkZ 分组显示后台运行角标，IDE 状态栏显示项目级后台运行计数；诊断导出清单附后台任务摘要。
- **并发多会话**：CodeZ 每个会话独立运行状态、发送队列与停止按钮，可真正并行多个会话；后台会话完成不再串扰当前查看会话。WorkZ 查看后台运行的会话时，轮次结束会自动刷新状态与历史。

## 行为变更

- **前台 `shell` / `code_run` 超时改为转后台**：不再在超时时杀死进程，而是移交后台注册表并返回 `bg_id`，agent 可自行决定等待或继续其他工作（需要旧行为时可对任务调用 `process_kill`）。
- **`process_control` 后台启动改为受管**：`start` 且 `wait=false` 的进程现在进入注册表（有输出捕获、会话绑定与整树终止），不再是无捕获的裸 spawn。
- **后台任务不跨应用重启存活**（Job 所有权语义）；重启后上次运行中的任务标记为 `interrupted`，已停放的续跑会补派发一次。后台任务不受轮次取消影响，删除会话会终止其后台任务。
- 每项目后台并发上限默认 4（可用环境变量 `AGENTZ_BG_MAX_PER_WORKSPACE` 调整），单任务最长运行默认 3600 秒（`AGENTZ_BG_MAX_RUNTIME_SECS`）。非 Windows 平台：前台命令仍因无 OS 沙箱被拒绝，`background=true` 走 `/bin/sh -c` 受管执行（setsid 进程组，终止时整组收尾）。
