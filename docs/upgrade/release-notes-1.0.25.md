# AgentZ 1.0.25 发布说明

发布日期:2026-10-26。完整英文变更见 `CHANGELOG.md` 的 1.0.25 条目。

## 修复

- **BotZ 成员拿不到 `pool_chat` / `pool_org`。** 成员(koi)的工具表没有绑定 pool 事件通道,导致这两个工具没有注册,成员无法在 pool 里交付、`@!` 交接或调用 `complete_todo`。现在与主 agent 一致。
- **1.0.24 无法构建。** 发布时误把 `Cargo.lock` 中 `ryu` 依赖的版本号一并改成了不存在的 1.0.24,已恢复为 1.0.23。1.0.24 标签作废,以 1.0.25 为准。

## BotZ 新增

- 每个办公室可设置最大并发成员数(0 表示使用全局默认 3)。
- 成员回合计入 Bot 的每日和每月 token 预算;达到 80% 提示,达到 100% 暂停,不再启动新回合。
- 父子任务:协调者在子任务描述里写 `Parent: <todo id>`,所有子任务结束后自动唤醒父任务负责人汇总并 `complete_todo`;看板卡片显示 `↳` 标记。
- 成员桌位上显示被 `@` 的未读消息数,打开桌位即视为已读。
- 评审面板新增 "Open PR":推送分支并用 `gh pr create` 开 PR。

## 已知限制

- 收件箱是基于 `@` 提及的前端视图,没有 `to_agent` / `read_at` 数据库字段。
- 父子关系靠描述里的 `Parent:` 约定,内核 todo 表没有 `parent_id` 列。
- Open PR 依赖本机已安装并登录 `gh`,且仓库配置了 `origin`。
