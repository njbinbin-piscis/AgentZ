# AgentZ 1.0.51 发布说明

发布日期：2026-11-04。完整变更见 `CHANGELOG.md` 的 1.0.51 条目。

## 新增

- **README 补上 BotZ。** 说明 Bot、定时例程、办公室，以及主管如何把工作拆到看板上。
- **办公室布局可以调整。** 看板可收起，拖动上边缘改变高度，卡片在每一列里滚动。成员桌子超出时单独滚动。对话区可拖动宽度，高度和宽度按办公室记住。
- **观察室。** 对话区拆成「对话」和「观察室」。观察室按时间列出交接消息，并高亮 `@提及`。输入 `@` 会列出成员名字。输入框与 CodeZ、WorkZ 使用同一套圆角样式。
