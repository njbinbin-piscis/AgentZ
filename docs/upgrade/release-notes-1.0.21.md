# AgentZ 1.0.21 发布说明

发布日期：2026-10-26。完整条目见 `CHANGELOG.md` 的 1.0.21 章节。

## 变化

- **状态栏显示本会话与本项目的累计 token 和花费。** 数据由内核按“会话 + 模型”持久化到 `model_usage` 表，重启、切换项目后仍然存在。
- **设置中新增“模型价格”。** 按供应商与模型填写每百万 token 的输入、输出价格和币种；花费为各模型用量乘以各自价格后求和，缺价格的模型不计入并在数字后加 `+`。移除了写死的 $3/$15 估算。

## 已知限制

- 本版本之前产生的用量没有按模型记录，不计入统计。
- 缓存命中的输入 token 暂按普通输入价计算。
