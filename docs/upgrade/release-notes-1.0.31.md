# AgentZ 1.0.31 发布说明

发布日期：2026-10-28。完整变更见 `CHANGELOG.md` 的 1.0.31 节。

## 修复

- **消息中 `@` 引用较大的非 ASCII 文件（如超过 12 KB 的中文文档）时，发送后永久“思考中”。** 内联文件截断时切在多字节字符中间导致 panic，回合被丢弃且界面收不到回复。现按字符边界截断，回合内 panic 会作为错误返回而不是卡住。
- **MCP 服务器每个回合都被重新启动**，失败的服务器也绕过退避每回合重试：缓存键序列化 `env`/`headers` 时 HashMap 顺序随机。现缓存键稳定。
- 后台任务输出尾部截断不再有同样的多字节 panic 风险。
