# AgentZ 0.9.12 发布说明

发布日期：2026-10-18。版本号与 `CHANGELOG.md` 的 0.9.12 条目一致。

本版本是极简修复版：修复 Windows 上文件打不开和 git 命令行窗口反复弹出的问题，去掉聊天窗口中多余的说明面板，只保留一行首次配置提示。

**本版本未通过上线验收门禁。** 下列未验收项见 `docs/upgrade/acceptance-0.9.12.md`，用户测试用例也在同一文件中。

## 修复

- Windows 上，项目路径不再带 `\\?\` 前缀。之前所有项目文件都会报 "File not found"。
- Windows 上，git 子进程不再弹出命令行窗口。之前窗口获得焦点会触发刷新，刷新又启动 git，形成循环。
- 任务详情、运行历史、通知收件箱在窗口获得焦点时的刷新合并为最多每 2 秒一次。

## 界面调整

- 移除 CodeZ、WorkZ 聊天窗口中的配置摘要和首次运行清单。
- 未配置模型 API 密钥时，CodeZ 空会话顶部显示一行提示，点击按钮打开设置。配置完成后提示消失。

## 已知限制

- 未通过验收门禁（台账中 M2 至 M9 与 MB 未全部通过，AZ-069 未完成）。
- 安装包未签名。macOS 安装包未公证，首次打开需要手动允许。
- macOS 与 Linux 安装包未在真机上运行。
- 0.9.11 的已知限制仍然适用，见 `docs/upgrade/release-notes-0.9.11.md`。
